# Port Rules (Always Apply)

- Follow spec/portfolio-master-spec.md as source of truth.
- Implement in PHASES. Do only the requested phase; do not jump ahead.
- Keep UI calm + editorial. Avoid SaaS templates: no glow, no neon gradients, no glass, no pill buttons/tags.
- No UI libraries (shadcn/MUI/Chakra). Tailwind only.
- Use the exact color tokens + fonts from spec.
- Prefer whitespace + typography; use thin borders over shadows.
- Before coding: list files to create/edit.
- After coding: summarize changes + how to run locally.
